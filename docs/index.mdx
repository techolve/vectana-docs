Vectana（ベクタナ）は、プロジェクトが使っているパッケージやランタイムを登録しておくと、**脆弱性**と**サポート終了**（EOL）を自動で監視して知らせてくれるアプリです。

「あのライブラリに脆弱性が出たけど、うちのどのプロジェクトが使ってる？」「この Python、いつまでサポートされる？」を、プロジェクトをまたいで一か所で確認できます。

## 仕組み

1. プロジェクトを作り、使っているパッケージ（lockfile）とランタイム（言語・DB・OS など）を登録します
2. Vectana が OSV と endoflife.date に問い合わせて、脆弱性と EOL を判定します
3. 新しく見つかったもの・状態が変わったものを、メールと Webhook でまとめて通知します
4. 以降は定期的に（初期設定では 6 時間ごと）自動でチェックし続けます

## データの出典

Vectana は次の外部データを使っています。各データの権利は提供元にあります。

- 脆弱性情報: [OSV.dev](https://osv.dev/)（Google が運営）。各アドバイザリは提供元（GitHub Advisory Database、PyPA Advisory Database など）のライセンスに従います。多くは [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) です
- サポート終了（EOL）情報: [endoflife.date](https://endoflife.date/)（MIT License）
