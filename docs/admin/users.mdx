## ロールと見える範囲 [#roles]

1 人のユーザーに、次のロールを**いくつでも**つけられます。どれもつけなければ、アサインされたプロジェクトだけが見えるメンバーです。ロールと、部署長かどうかによって、見えるプロジェクトとできる操作が決まります。

| 誰 | 見えるプロジェクト | できること |
| --- | --- | --- |
| グループ管理者 | すべて | すべての会社・部署・ユーザーの管理、システム設定、すべての顧客・見積 |
| 会社管理者 | 自分の会社のすべて（営業中を含む） | 自分の会社の部署・ユーザーの管理、自社の顧客・見積 |
| 営業 | 自分の会社のすべて（営業中を含む） | 自社の顧客・見積の作成と編集、営業中のプロジェクトの管理 |
| 経理 | 自分の会社の受注済みのプロジェクト（閲覧のみ） | 自社の顧客・見積・単価を見る |
| PMO | すべての会社の受注済みのプロジェクト（閲覧のみ） | すべての顧客を見る |
| 部署長 | 担当する部署とその配下の部署の受注済みのプロジェクト（＋アサインされたもの） | なし |
| メンバー | アサインされたプロジェクトだけ | なし |
| BP（協力会社のユーザー） | アサインされたプロジェクトだけ | なし |

- 受注前の「営業中」のプロジェクトは、営業・管理者・そのプロジェクトのメンバーにだけ表示されます（[プロジェクト](/guides/projects#stages)）
- 人ごとの単価（人日）は、同じ会社の管理者・営業・経理にだけ表示されます。見積の原価計算に使います（[営業：顧客と見積](/guides/sales#money)）
- 見えないプロジェクトは、一覧にも出ず、URL を直接開いても「見つかりません」になります
- 会社管理者・グループ管理者・部署長は、見えるプロジェクトでオーナーと同じ操作ができます
- アサインされたプロジェクトでできる操作は、プロジェクト内のロール（オーナー・メンバー・閲覧のみ）で決まります（[プロジェクト](/guides/projects)）

### BP（協力会社）のユーザー

BP の会社に所属するユーザーには、次の制限があります。

- ロールはつけられません（管理者・営業などにはできません）
- 顧客・段階・見積などの金額は表示されません
- プロジェクトを作成できません
- プロジェクトのオーナーにできません
- 他のユーザーを検索できません

## ユーザーを招待する

![招待タブ](/screenshots/ja/admin-invitations.png)

「組織管理」→「招待」タブで招待します。会社管理者は自分の会社に、グループ管理者はどの会社にも招待できます。

| 項目 | 内容 |
| --- | --- |
| メールアドレス | 招待する人のアドレス |
| 表示名 | 任意。本人があとで変更できます |
| ロール | 任意。複数選べます。グループ管理者はグループ管理者だけが付与できます |
| メールの言語 | 招待メールと、作られるアカウントの言語 |
| 所属部署 | 任意。複数選べます（兼務）。「主所属」を 1 つと、部署長かどうかを指定します |

「招待メールを送る」を押すと、招待メールが届きます。招待リンクの有効期限は 7 日間です。

:::tip
メールを送れなかった場合は、画面に招待リンクが表示されます。「コピー」して、チャットなどで直接渡してください。
:::

保留中の招待は一覧に表示され、「取り消し」で無効にできます。同じアドレスにもう一度招待すると、前の招待は自動的に取り消されます。

## ユーザーを編集する

![ユーザータブ](/screenshots/ja/admin-users.png)

「組織管理」→「ユーザー」タブで、ユーザーの一覧（ロール・所属部署・単価・状態）を確認し、「編集」から次の項目を変更できます。

- 表示名
- ロール（複数可）
- 単価（人日）。見積の原価計算に使います
- ログインを許可（オフにすると、そのユーザーはログインできなくなります）
- 所属部署（兼務・主所属・部署長）

自分自身のロールの変更と、ログインの停止はできません。会社管理者は、グループ管理者の変更や、グループ管理者のロールの付与はできません。
