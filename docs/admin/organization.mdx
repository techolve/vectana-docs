---
title: 組織の構成
description: グループ・会社・部署の考え方と、会社と部署の登録・変更・削除。
---

Vectana は、1 つのグループの中に複数の会社があり、それぞれの会社に部署がある、という構成を前提にしています。サイドバーの「組織管理」で管理します（管理者のみ表示されます）。

```txt
グループ（Vectana 全体）
├── 親会社
│   ├── 開発本部
│   │   ├── 第1開発部
│   │   └── 第2開発部
│   └── 営業部
├── 関連会社
│   └── …
└── BP（協力会社）
```

## 会社

「組織管理」→「会社」タブで管理します。会社の追加・名前の変更・種別の変更・削除ができるのは**グループ管理者**だけです。

| 種別 | 説明 |
| --- | --- |
| 親会社 | グループの中心となる会社 |
| 関連会社 | グループ内の会社 |
| BP（協力会社） | グループ外の協力会社。所属するユーザーは、アサインされたプロジェクトだけを見られます |

- プロジェクトを作れるのは、親会社と関連会社だけです
- ユーザーかプロジェクトが残っている会社は削除できません
- 管理者がいる会社を BP に変更することはできません。先にその会社の管理者をメンバーに変更してください

## 部署

「組織管理」→「部署」タブで管理します。グループ管理者はすべての会社の部署を、会社管理者は自分の会社の部署を管理できます。複数の会社を管理できる場合は、右上で対象の会社を切り替えます。

- 部署は入れ子にできます（本部 > 部 > 課 など）。「親部署」を選んで追加・移動します
- 部署を自分の配下に移動することはできません
- 配下に部署がある部署は削除できません。先に配下の部署を削除してください

部署は、[ユーザーの所属](/admin/users) と、[プロジェクトの担当部署](/guides/projects) に使います。
