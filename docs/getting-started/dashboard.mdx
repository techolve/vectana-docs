ダッシュボードには、**自分が見られるプロジェクト全体**の状況がまとまっています。どのプロジェクトが見えるかは [権限](/admin/users) によって決まります。

![ダッシュボード](/screenshots/ja/dashboard.png)

## タスク

いちばん上に、未完了のタスクが期限切れ・期限の近い順に出ます。「自分」「チーム」「未割り当て」で切り替えられます。詳しくは [タスク](/guides/tasks#dashboard) を参照してください。

## 集計カード

タスクの下に 6 枚のカードが並びます。

| カード | 内容 |
| --- | --- |
| プロジェクト | 見えているプロジェクトの数 |
| パッケージ | 登録されているパッケージの合計 |
| CRITICAL / HIGH | 未対応の脆弱性のうち、重大度が CRITICAL・HIGH のもの |
| EOL 済み | サポートが終了したパッケージ・ランタイム |
| EOL 間近 | まもなくサポートが終了するもの（何日前から表示するかは管理者が設定） |

件数がある CRITICAL・HIGH・EOL のカードは色が付きます。カードを押すと、[脆弱性](/guides/vulnerabilities) や [EOL](/guides/eol) の一覧に移動します。

その下には、脆弱性への対応を進めるための 3 枚のカードがあります。

| カード | 内容 |
| --- | --- |
| 自分の担当（未完了） | 自分が担当者になっている、未対応・確認済みの脆弱性 |
| 期限切れ | 期限を過ぎても未完了の脆弱性。件数があると色が付きます |
| 担当者未定の未対応 | 未対応のまま、担当者が決まっていない脆弱性 |

カードを押すと、その条件で絞り込んだ脆弱性の一覧が開きます。担当者や期限の決め方は [脆弱性](/guides/vulnerabilities#詳細パネル) を参照してください。

## プロジェクトの状況

プロジェクトごとに、未対応の脆弱性の件数（重大度別）、EOL の件数、パッケージ数、最後にスキャンした日時を一覧にしています。

並び順は「CRITICAL が多い順 → HIGH が多い順 → EOL 済みが多い順」です。上にあるプロジェクトほど、先に対応したほうがよいものです。

## 対応が必要な項目

画面下部では、タブを切り替えて次の 2 つを確認できます。

- **脆弱性**: 未対応の脆弱性（重大度の高い順に最大 20 件）。ここから直接、対応状況を変更できます
- **EOL**: サポート終了済み・まもなく終了のもの（最大 20 件）

すべてを見るには、サイドバーの「脆弱性」「EOL」を開いてください。

## 組織別ダッシュボード [#org]

![組織別ダッシュボード](/screenshots/ja/org-dashboard.png)

サイドバーの「組織別」では、会社・部署ごとに次の数字を一覧にします。部署の数字には配下の部署を含みます。

| 列 | 内容 |
| --- | --- |
| プロジェクト | その会社・部署のプロジェクト数 |
| 未対応 | 未対応の脆弱性（重大度別） |
| 期限超過 | 期限を過ぎても未対応・確認済みのままの脆弱性。いちばん長く超過している日数も出ます |
| EOL | サポート終了済み・まもなく終了のもの |
| 直近の EOL | いちばん近い EOL 日までの日数（過ぎていれば超過日数） |

期限は脆弱性ごとの期限、なければ [システム設定の SLA](/admin/settings#sla) で決まります。行の矢印で配下の部署を開閉でき、右上で会社を絞り込めます。「CSV ダウンロード」で同じ表を CSV で保存できます。

下のタブでは、期限超過の脆弱性と EOL が近いものを一覧で確認できます。自分が見られるプロジェクトだけを集計するので、一部しか見えない会社・部署には「一部のみ」と表示されます。

管理者と部署長には、同じ内容が [週次レポート](/admin/settings#report) としてメールで届きます。
