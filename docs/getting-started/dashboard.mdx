---

ダッシュボードには、**自分が見られるプロジェクト全体**の状況がまとまっています。どのプロジェクトが見えるかは [権限](/admin/users) によって決まります。

## 集計カード

![ダッシュボード](/screenshots/ja/dashboard.png)

画面上部に 6 枚のカードが並びます。

| カード | 内容 |
| --- | --- |
| プロジェクト | 見えているプロジェクトの数 |
| パッケージ | 登録されているパッケージの合計 |
| CRITICAL / HIGH | 未対応の脆弱性のうち、重大度が CRITICAL・HIGH のもの |
| EOL 済み | サポートが終了したパッケージ・ランタイム |
| EOL 間近 | まもなくサポートが終了するもの（何日前から表示するかは管理者が設定） |

件数がある CRITICAL・HIGH・EOL のカードは色が付きます。カードを押すと、[脆弱性](/guides/vulnerabilities) や [EOL](/guides/eol) の一覧に移動します。

## プロジェクトの状況

プロジェクトごとに、未対応の脆弱性の件数（重大度別）、EOL の件数、パッケージ数、最後にスキャンした日時を一覧にしています。

並び順は「CRITICAL が多い順 → HIGH が多い順 → EOL 済みが多い順」です。上にあるプロジェクトほど、先に対応したほうがよいものです。

## 対応が必要な項目

画面下部では、タブを切り替えて次の 2 つを確認できます。

- **脆弱性**: 未対応の脆弱性（重大度の高い順に最大 20 件）。ここから直接、対応状況を変更できます
- **EOL**: サポート終了済み・まもなく終了のもの（最大 20 件）

すべてを見るには、サイドバーの「脆弱性」「EOL」を開いてください。
