---
title: AI から操作する（MCP）
description: 個人用トークンと Vectana の MCP サーバで、Claude などの AI クライアントから脆弱性のトリアージやプロジェクト・見積・タスクを操作する方法。
---

Vectana には、Claude Desktop や Claude Code などの AI クライアントから操作するための [MCP](https://modelcontextprotocol.io/) サーバがあります。「自分に割り当てられた CRITICAL の脆弱性をまとめて」「この package-lock.json を社内ツールに取り込んで」「ACME 社の商談に初期見積を作って」のように、普段の言葉で頼めます。

AI は**あなたの権限で**操作します。画面で見えないプロジェクトや、変更できない項目は、AI からも見えず変更もできません。

## 個人用トークンを発行する

「個人設定」の「個人用トークン（AI・スクリプト連携）」で発行します。

![個人用トークン](/screenshots/ja/personal-tokens.png)

1. 用途（例: `Claude Desktop`）を入力します
2. 権限を選びます
   - **読み取りのみ**: 一覧や詳細を見るだけ。登録・変更はできません
   - **読み書き**: あなたができる操作をすべて行えます
3. 有効期限を選んで「発行」を押すと、`vcu_` で始まるトークンと MCP の設定例が表示されます

:::warning
トークンは**発行したときに一度だけ**表示されます。紛失した場合や漏れた可能性がある場合は、ゴミ箱で失効させて発行し直してください。
:::

まずは「読み取りのみ」で試し、慣れてから「読み書き」にするのがおすすめです。個人用トークンでは、ほかのトークンの発行や失効はできません。

## MCP クライアントに登録する

### Claude Desktop など

設定ファイル（Claude Desktop なら `claude_desktop_config.json`）に追加します。発行画面の設定例をそのままコピーできます。

```json
{
  "mcpServers": {
    "vectana": {
      "command": "npx",
      "args": ["-y", "@techolve/vectana-mcp"],
      "env": {
        "VECTANA_URL": "https://vectana.example.com",
        "VECTANA_TOKEN": "vcu_..."
      }
    }
  }
}
```

### Claude Code

```bash
claude mcp add vectana \
  -e VECTANA_URL=https://vectana.example.com \
  -e VECTANA_TOKEN=vcu_... \
  -- npx -y @techolve/vectana-mcp
```

Node.js 20 以上が必要です。

### 設定できる環境変数

| 変数 | 内容 |
| --- | --- |
| `VECTANA_URL` | Vectana の URL（必須） |
| `VECTANA_TOKEN` | 個人用トークン（必須） |
| `VECTANA_LOCALE` | `ja` または `en`。エラーメッセージの言語 |
| `VECTANA_READ_ONLY` | `1` にすると、読み取り系のツールだけを AI に見せます |

## できること

| 機能 | できること |
| --- | --- |
| ダッシュボード | 自分のダッシュボード、組織別ダッシュボードの数字を確認 |
| 脆弱性 | 一覧・詳細の確認、対応状況・担当者・期限の変更、コメント |
| パッケージ | 一覧、手動登録、lockfile・SBOM の取り込み、今すぐスキャン |
| EOL | EOL の一覧、ランタイムの一覧と登録 |
| プロジェクト | 一覧・詳細、作成・更新（商談のステージ変更を含む）、メンバーのアサイン |
| 顧客 | 一覧・詳細、作成・更新、担当者の追加 |
| 見積 | 一覧・詳細、作成・更新（明細を含む） |
| タスク | 自分のタスク、プロジェクトのタスク、作成・更新、セキュリティ対応タスクの作成 |
| スプリント | 一覧、バーンダウン、ベロシティ、作成・更新 |

lockfile や SBOM は、AI クライアントが動いているパソコン上のファイルパスを伝えればそのまま取り込めます（[対応形式](/guides/packages)）。

:::note
AI が誤ってデータを消さないよう、**削除の操作はできません**。削除は画面から行ってください。
:::

## 頼み方の例

- 「Vectana で自分が担当の脆弱性のうち、期限切れのものを一覧にして」
- 「社内ツールのプロジェクトに `./package-lock.json` を取り込んで、スキャンして」
- 「lodash の脆弱性は影響しないので ignored にして、理由をコメントに残して」
- 「タスク化されていない脆弱性からセキュリティ対応タスクを作って、自分に割り当てて」
- 「ACME 社の商談に、基本設計 10 人日・詳細設計 15 人日で初期見積を作って」
- 「今のスプリントのバーンダウンを見て、終わりそうか教えて」
