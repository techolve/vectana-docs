Vectana は、新しく見つかった脆弱性と、EOL の状態が変わったもの（まもなく終了・サポート終了）を通知します。1 回のチェックで見つかったものは、宛先ごとに **1 通にまとめて**送ります。

## メール通知

プロジェクトに**アサインされているメンバー**に、メールが届きます。メールの言語は、受け取る人が選んでいる表示言語です。

個人設定の「メール通知」で、次のように変更できます。

| 設定 | 内容 |
| --- | --- |
| メールで受け取る | オフにすると、通知メールが届かなくなります |
| 通知する重大度 | この重大度以上の脆弱性だけを通知します（例: HIGH 以上） |

:::note
重大度が UNKNOWN（不明）の脆弱性は、しきい値に関係なく通知します。EOL の通知も、重大度の設定に関係なく届きます。
:::

## Discord・Slack に通知する（Webhook）

チームのチャンネルに通知したい場合は、プロジェクトの「通知（Webhook）」タブで Webhook を登録します。この設定は、プロジェクトを管理できる人（オーナー・管理者・部署長）だけが行えます。

<Steps>
  <Step title="Webhook URL を発行する">
    **Discord**: チャンネルの設定 → 連携サービス → ウェブフック → 新しいウェブフック → 「ウェブフック URL をコピー」

    **Slack**: Slack アプリの「Incoming Webhooks」を追加し、投稿先のチャンネルを選んで Webhook URL をコピー
  </Step>
  <Step title="Vectana に登録する">
    種類（Discord / Slack）を選び、URL を貼り付けます。通知する重大度と、通知の言語を選んで「追加」を押します。
  </Step>
  <Step title="テスト送信する">
    一覧の「テスト送信」を押して、チャンネルにメッセージが届くか確認します。
  </Step>
</Steps>

- URL は `https://` で始まるものだけ登録できます
- 「有効」のチェックを外すと、削除せずに一時停止できます
- 1 つのプロジェクトに複数の Webhook を登録できます

## 通知のルール

- 同じ脆弱性を、同じ宛先に 2 回通知することはありません
- EOL は「まもなく終了」になったとき、「サポート終了」になったときの、それぞれ 1 回ずつ通知します
- 状態を「確認済み」「無視」にした脆弱性は通知されません
- 送信に失敗した場合は、次回のチェックで再送します（見つかってから 7 日間）
