Vectana では、システムや案件ごとに**プロジェクト**を作ります。引き合いから開発・保守まで、同じプロジェクトで追います。パッケージやランタイム、通知先、見積もプロジェクトごとに登録します。

## プロジェクトを作る

![プロジェクト一覧](/screenshots/ja/projects.png)

サイドバーの「プロジェクト」→「新規作成」から作成します。

| 項目 | 内容 |
| --- | --- |
| 名前 | プロジェクトの名前 |
| 説明 | 任意 |
| 会社 | プロジェクトが属する会社。グループ管理者以外は自分の会社だけ選べます |
| 担当部署 | 任意。[部署長](/admin/users) は、担当する部署（とその配下）のプロジェクトを見られます |
| 段階 | 社内システムなど営業を通らないものは「開発中」か「運用・保守」から始めます。引き合いなどの営業の段階を選べるのは、営業ロールと管理者だけです |
| 進め方 | ウォーターフォール（ガント）かスクラム（ボード）。あとから変えられます |
| 顧客 | 営業ロールと管理者だけが選べます。空なら社内のプロジェクトです |

作成した人は、そのプロジェクトの**オーナー**になります。

## 段階とタブ [#stages]

プロジェクトは次の段階のどれかにあります。

| 段階 | 意味 | 一覧のタブ |
| --- | --- | --- |
| 引き合い | 問い合わせを受けた | 営業中 |
| 提案・見積 | 提案書・見積を作成中 | 営業中 |
| 商談中 | 見積を提出し、回答待ち・交渉中 | 営業中 |
| 受注 | 受注した（開発の開始前） | 進行中 |
| 開発中 | 開発中 | 進行中 |
| 運用・保守 | 納品後の運用・保守 | 保守 |
| 保留 | 一時的に止まっている | 終了・アーカイブ |
| 失注 | 失注した | 終了・アーカイブ |

受注するまでのプロジェクト（営業中）は、営業ロール・管理者・そのプロジェクトのメンバーにだけ表示されます。受注・開発中・運用・保守のどれかに進めると、受注日が記録され、部署長や PMO・経理にも見えるようになります。

段階を変えられるのは営業ロールと管理者です。プロジェクトのオーナーは、受注・開発中・運用・保守の間だけ変えられます（たとえば、納品したら「運用・保守」へ）。

プロジェクト一覧は「表」と「パイプライン」を切り替えられます。営業中タブは最初にパイプラインを出します。パイプラインでは段階ごとの列にカードが並び、カードを別の列へドラッグすると段階が変わります。次のアクションの期日を過ぎたカードは赤く表示されます。営業の使い方は [営業：顧客と見積](/guides/sales) を見てください。

:::note
BP（協力会社）のユーザーはプロジェクトを作成できません。
:::

## プロジェクトの画面

![プロジェクトの画面（脆弱性タブ）](/screenshots/ja/project-vulns.png)

プロジェクトを開くと、上部に段階・顧客・会社・部署と、未対応の脆弱性・EOL の件数が表示されます。タブで次の画面を切り替えます。

| タブ | 内容 |
| --- | --- |
| 概要 | 顧客・進め方・責任者・期間・営業担当と、受注金額や商談の状況。「編集」で変更します |
| タスク | ガント・ボード・一覧でタスクを管理（[タスク](/guides/tasks)） |
| セキュリティ対応 | パッケージ・ランタイムのアップグレードのタスクと、まだタスクになっていない脆弱性・EOL（[セキュリティ対応タスク](/guides/tasks#security)） |
| 見積 | このプロジェクトの見積（[営業：顧客と見積](/guides/sales#estimates)）。BP のユーザーには表示されません |
| 脆弱性 | このプロジェクトで見つかった脆弱性（[脆弱性](/guides/vulnerabilities)） |
| EOL | パッケージとランタイムのサポート状況、ランタイムの登録（[EOL](/guides/eol)） |
| パッケージ | 監視するパッケージの登録と lockfile の取り込み（[パッケージの登録](/guides/packages)） |
| メンバー | このプロジェクトにアサインされている人 |
| 通知（Webhook） | Discord・Slack への通知設定（管理できる人のみ） |
| 設定 | 名前・説明・担当部署の変更、削除（管理できる人のみ） |

右上の「今すぐスキャン」を押すと、定期チェックを待たずにすぐ照会します。

## メンバーとロール

![メンバータブ](/screenshots/ja/project-members.png)

「メンバー」タブで、ユーザーをプロジェクトにアサインします。名前やメールアドレスで検索し、ロールを選んで追加します。

| ロール | できること |
| --- | --- |
| オーナー | すべての操作（設定・削除・メンバー・Webhook を含む） |
| メンバー | 閲覧、パッケージとランタイムの登録、脆弱性の対応状況の変更 |
| 閲覧のみ | 閲覧だけ |

アサインされたメンバーには、[通知メール](/guides/notifications) が届きます。

会社管理者・グループ管理者・担当部署の部署長は、アサインされていなくてもオーナーと同じ操作ができます。BP（協力会社）のユーザーをオーナーにすることはできません。

## 設定と削除

「設定」タブで、名前・説明・担当部署を変更できます。段階・進め方・責任者・期間などは「概要」タブの「編集」で変更します。

「プロジェクトの削除」では、確認のためにプロジェクト名を入力します。削除すると、パッケージ・ランタイム・検知結果・Webhook もすべて削除され、元に戻せません。
