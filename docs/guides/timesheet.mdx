---
title: 実績工数と見積との比較
description: 週ごとの実績工数の入力、Excel からの貼り付け、週の提出、プロジェクトの「見積と実績」の見方。
---

サイドバーの「実績工数」で、タスクごとの作業時間を 1 週間（月曜〜日曜）単位で入力します。入れた時間は、プロジェクトの「見積と実績」タブで見積の工数と比べられます。

## 入力する [#enter]

1. 「行を追加」で、作業する行を選びます
   - 自分の未完了タスクは一覧からワンクリックで追加できます
   - プロジェクトを選んで、タスクを選ぶか「タスクなし（プロジェクト全般）」にします
   - 社内会議や研修など、プロジェクト外の作業は作業名を入れます
2. 日ごとのセルに時間を入れます（0.5 のような小数も可）
3. 「保存」で週の内容を保存します

先週と同じタスクを続けるときは、「先週と同じ行を並べる」で行だけをコピーできます（時間は空のまま）。

### Excel から貼り付ける [#paste]

Excel やスプレッドシートで範囲をコピーし、貼り付けたい左上のセルを選んで貼り付けると、行と日にまたがってまとめて入ります。行が足りない分は貼り付けないので、先に行を追加しておきます。

### 表示される数字 [#numbers]

| 列 | 意味 |
| --- | --- |
| 計 | その行の週の合計 |
| 残り見積 | タスクの「見積（時間）」から、これまでの全員の実績を引いた残り。マイナスは見積超過です |
| 日計 | その日の合計。24 時間を超える日は保存できません |
| 週合計 / 所定 | 週の合計と所定時間（40 時間）。超えた分も表示します |

## 週を提出する [#submit]

入力が終わったら「週を提出」を押します。未保存の入力があれば保存してから提出します。提出したあとも直せます。直すために「提出を取り消す」こともできます。

## 誰の工数を見られるか [#who]

| 誰 | 見る | 直す |
| --- | --- | --- |
| 本人 | 自分の工数 | 自分の工数 |
| 部署の責任者 | 配下の部署の人の工数 | できません |
| 会社管理者 | 自社の全員の工数 | 自社の全員の工数 |
| グループ管理者 | すべて | すべて |

見られる人が複数いる場合、画面の右上で人を切り替えられます。

## 見積と実績 [#actuals]

プロジェクトの「見積と実績」タブで、受注した見積と実績工数を比べます。1 人日 = 8 時間で換算します。BP（協力会社）のユーザーには表示されません。

- **工数（実績 / 見積）**: 受注した一括の見積（初回開発・追加開発）の工数の合計と、これまでの実績。90% を超えると黄色、100% を超えると赤になります
- **今月の実績**: 今月入力された工数
- **実績原価**: 実績工数 × 各人の単価。単価が見られる人（営業・管理者・経理）にだけ表示されます（[金額が見える人](/guides/sales#money)）
- **フェーズ別**: 子タスクを持つ上位タスクをフェーズとして集計します。フェーズの見積は、配下のタスクの「見積（時間）」の合計です。タスクに付いていない実績は「フェーズ外」にまとまります
- **メンバー別**: 人ごとの実績

ガントでフェーズを作り（[タスク](/guides/tasks)）、タスクに見積時間を入れておくと、どのフェーズで見積を超えているかがわかります。
