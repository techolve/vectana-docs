title: 営業：顧客と見積

---

営業ロールを持つ人と管理者は、顧客を登録し、引き合いの段階からプロジェクトを作って、見積・受注までを Vectana で追えます。

## 顧客 [#customers]

サイドバーの「顧客」で、取引先の会社と担当者を管理します。組織管理の「会社」（グループ会社・協力会社）とは別のマスタです。

- 「顧客を追加」で会社名と業種を入れて作成し、詳細画面の「編集」で所在地・電話・支払条件・請求書の送付先・Web サイト・メモを入れます
- 「担当者を追加」で、先方の担当者（名前・部署・役職・メール・電話）を登録します。1 人を「主担当」にできます
- 詳細画面の下に、その顧客のプロジェクトと見積が並びます。失注したものも分析用に残ります
- プロジェクトがある顧客は削除できません

顧客は、それを担当する自社（グループ会社）に属します。営業ロールで扱えるのは自社の顧客だけです。

| 誰 | 顧客 |
| --- | --- |
| グループ管理者 | すべて見る・編集する |
| 会社管理者・営業 | 自社の顧客を見る・編集する |
| 経理 | 自社の顧客を見る |
| PMO | すべて見る |
| それ以外・BP | 見られません |

## 商談を進める [#deals]

1. 「プロジェクト」→「新規作成」で、段階を「引き合い」にして顧客を選びます。見込み金額と確度も入れられます
2. 「概要」タブの「編集」で、確度・次のアクションと期日・営業担当を更新します
3. パイプラインでカードをドラッグして、提案・見積 → 商談中 と進めます
4. 見積を「受注」にすると、プロジェクトは自動で「受注」に進みます

失注したら、段階を「失注」にして、失注理由と競合を残します。失注・保留したプロジェクトは「終了・アーカイブ」タブに移り、普段の一覧には出ません。

段階ごとの意味と、誰に見えるかは [プロジェクト](/guides/projects#stages) を見てください。

## 商談メモ [#activities]

プロジェクトの「商談メモ」タブに、打合せ・電話・メールの記録を残します。日付・参加者・内容を入れて「記録する」を押すと、新しい順に並びます。

「次のアクション」を入れると、担当者と期限つきの**タスク**になります。担当者の「自分のタスク」に入り、プロジェクトの「次のアクション」（パイプラインのカードに出るもの）も最新の内容に変わります。担当者を選ばなければ自分になります。

- アクションの完了は、タスク一覧やダッシュボードでタスクを完了にします。商談メモの側にも完了が表示されます
- 右側に、案件の次のアクションと、まだ終わっていないアクションが並びます
- メモを消しても、作られたタスクは残ります

商談メモを書けるのは、営業・管理者と、プロジェクトに書き込み権限のあるメンバーです。BP のユーザーには表示されません。

## 見積 [#estimates]

見積はプロジェクトの「見積」タブで作ります。1 つのプロジェクトに複数の見積を持てます。初回開発のあとの追加開発や、保守契約の更新も、同じプロジェクトの新しい見積として追加します。受注・失注は見積ごとに記録します。

| 項目 | 内容 |
| --- | --- |
| 見積 | 見積の名前（例：初回開発（第 3 版）） |
| 種類 | 初回開発・追加開発・保守・その他 |
| 状態 | 作成中・提出済み・受注・失注。受注・失注にすると、その日が記録されます |
| 請求 | 一括か月額。保守は月額にします |
| 金額 | 税抜の金額。月額なら 1 か月分 |
| 見積日・提出期限・契約期間の終わり | 任意 |
| 内訳 | 内容・担当・工数（人日）・単価。担当を選んで単価を空にすると、その人の単価が入ります |

内訳を入れると、工数は内訳の合計になり、原価（工数 × 単価）と利益率が計算されます。内訳がなければ、工数を直接入れます。

内訳に入った単価は、保存したときの値で残ります。あとでユーザーの単価を変えても、過去の見積は変わりません。

### 金額が見える人 [#money]

| 情報 | 営業・管理者・経理 | プロパーのメンバー | BP のユーザー |
| --- | --- | --- | --- |
| 見積金額・工数・利益率 | 見える | 見える | 見えない |
| 人ごとの単価・原価 | 見える | 見えない | 見えない |
| 顧客・段階・受注金額 | 見える | 見える | 見えない |
| タスク・脆弱性（参加しているプロジェクト） | 見える | 見える | 見える |

プロパーのメンバーに金額を隠さないのは、キャリアを積むうえで知っておいてほしい情報だからです。人ごとの単価は給与が推測できてしまうので、営業・管理者・経理（同じ会社）だけに表示します。

受注したあと、何回に分けて請求するかは [請求予定と入金](/guides/billing) で決めます。

見積を作成・編集できるのは、営業ロール（自社）と管理者です。単価は「組織管理」→「ユーザー」で設定します（[ユーザーと権限](/admin/users#roles)）。
