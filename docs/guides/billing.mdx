---
title: 請求予定と入金
description: 受注した見積から段階請求・月額請求の予定を作り、経理が請求済・入金済を記録する流れ。
---

受注した見積を、何回に分けていつ請求するかを「請求予定」として登録します。請求書そのものは会計ソフトで発行し、Vectana では請求したこと・入金されたことを記録します。

## 請求予定を作る（営業） [#plan]

1. プロジェクトの「見積」タブを開きます。受注した見積があると、下に「請求予定」が表示されます
2. 「請求予定を作る…」で見積を選びます
3. 分け方を決めます
   - **一括の見積**: 「100」「30 / 70」「50 / 50」「30 / 40 / 30」から分割を選ぶと、金額と請求日（プロジェクトの開始月〜終了月に割り振り）が入ります。各回の内容・日付・金額は自由に直せます
   - **月額の見積**: 開始月と月数を入れて「並べる」と、「2026年12月分」のように毎月の請求が並びます
4. 「保存」で登録します。合計が見積金額と違うときは黄色で知らせます

請求予定を作り直すと、まだ「予定」の回だけが置き換わります。請求済・入金済の回はそのまま残ります。受注した見積にまだ請求予定がないときは、「請求予定」の欄にその見積の名前が出ます。

## 請求済・入金済を記録する（経理） [#record]

サイドバーの「請求」で、月ごとの請求を一覧します。

- 上のカードに「今月の請求予定」「入金待ち」「今月の入金」「入金遅れ」の件数と金額が出ます。カードを押すと、その状態だけに絞り込みます
- 一覧には、その月が請求予定日の回、その月に入金された回、まだ入金されていない請求済の回（入金遅れを含む）が並びます
- 「請求済にする」で請求日と入金期日を入れます。入金期日の既定は、請求日の翌月末です
- 「入金済にする」で入金日を入れます
- 間違えたときは「取り消す」で一つ前の状態に戻せます

入金期日を過ぎても入金済になっていない回は「入金遅れ」として赤く表示されます。

「CSV 出力」で、表示中の月・状態の一覧を CSV（Excel でそのまま開ける UTF-8）でダウンロードできます。会計ソフトへの登録や、月次の締めに使えます。

## 誰が何をできるか [#who]

| 誰 | 請求予定を作る・直す | 請求済・入金済を記録 | 「請求」ページ |
| --- | --- | --- | --- |
| 営業 | 自社のプロジェクト | できません | 使えません（プロジェクトの「見積」タブで見ます） |
| 経理 | できません | 自社のプロジェクト | 自社の請求 |
| 会社管理者 | 自社のプロジェクト | 自社のプロジェクト | 自社の請求 |
| グループ管理者 | すべて | すべて | すべての会社（会社で絞り込めます） |
| プロパーのメンバー | できません | できません | 使えません（プロジェクトの請求予定は見えます） |
| BP のユーザー | 見えません | 見えません | 使えません |
